# tvtimi-site

Pages publiques de [TvTimi](https://tvtimi.fr), en français, anglais et espagnol : conditions d'utilisation, politique de confidentialité, mentions légales, suppression du compte et contact. Publiées par GitHub Pages.

Les textes vivent dans `src/*.md` ; `python3 build.py` génère toutes les pages, accueil et 404 comprises. Après une modification des conditions d'utilisation ou de la politique de confidentialité : changer la date de version en tête des six textes et `LegalDocuments.version` dans l'app.
