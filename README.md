# tvtimi-site

Pages publiques de [TvTimi](https://tvtimi.fr) : conditions d'utilisation et politique de confidentialité, en français, anglais et espagnol. Publiées par GitHub Pages.

Les textes vivent dans `src/*.md`. Après une modification : `python3 build.py`, puis changer la date de version en tête des six textes et `LegalDocuments.version` dans l'app.
