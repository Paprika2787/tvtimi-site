# Condiciones de uso de TvTimi

Versión del 5 de octubre de 2026.

## El servicio

TvTimi es una aplicación móvil gratuita para guardar la lista de las series y los animes que ves, marcar los episodios vistos y valorarlos. TvTimi no emite ningún vídeo.

La aplicación se edita a título no profesional con el nombre TvTimi. Contacto: contact@tvtimi.fr.

Al crear una cuenta, aceptas estas condiciones y la política de privacidad.

## Tu cuenta

Debes tener 15 años o más para crear una cuenta.

Indica una dirección de correo que uses: sirve para confirmar tu cuenta y para elegir una nueva contraseña. Tu contraseña es personal. Si crees que otra persona la conoce, cámbiala desde la pantalla de inicio de sesión.

Puedes eliminar tu cuenta en cualquier momento desde Perfil, Eliminar mi cuenta. Todos tus datos se borran entonces.

## Lo que te comprometes a no hacer

Usar TvTimi para algo distinto de un uso personal, intentar acceder a los datos de otra cuenta, perturbar el funcionamiento del servicio o consultarlo de forma automatizada.

En caso de incumplimiento, la cuenta afectada puede suspenderse o eliminarse.

## El catálogo

La información sobre las series y los animes (títulos, resúmenes, imágenes, fechas de emisión) procede de TMDB. Esta aplicación utiliza TMDB y las API de TMDB, pero no está respaldada, certificada ni aprobada por TMDB. Esta información puede contener errores u omisiones; TvTimi la muestra tal cual.

## Disponibilidad

TvTimi se ofrece gratis, tal cual. Hacemos lo posible para que funcione bien, sin poder garantizar la ausencia de interrupciones o errores. El servicio puede cambiar, suspenderse por mantenimiento o terminar: en ese caso, se te avisa en la aplicación y puedes exportar tus datos antes.
